## 0. 한 줄 목적과 범위

가상자본 1억 원씩 네 계좌를 같은 날 출발시켜 한국 증시에서 "수급 규칙"과 "Claude 재량"을 벤치마크와 비교한다. 어떤 주문도 밖으로 나가지 않는다.

**범위 아님**: 실제 주문, KIS 모의투자 서버 미러링(뒤의 검증 도구 후보), 장중 관측치(서버가 장중에 꺼져 있음, K4), 파생·공매도, Claude 계좌 백테스트(D17).

## 2. 공통 원칙 — 미국 책 그대로

제안은 모델·집행은 코드(검증기), 체결은 결정 뒤 첫 관측치(봉 날짜 > 기준 거래일), 출발일 종가 동결, 실패는 그날 주문 없음, 하루 호출 상한은 **미국·한국 책이 함께** 20회,
규칙 계좌는 동결 대조군, 모든 경로는 운영자 전용, 표본 부족은 null.

## 3. 사용자가 얻는 것

- 같은 날 출발한 네 계좌의 순자산 곡선과 통계(미국 책과 같은 화면 패턴, 통화만 ₩)
- 규칙 계좌: "외국인·기관이 함께 사는 종목을 따라가면 KODEX 200을 이기는가"
- Claude 계좌: 한국 매크로·수급·재무·사건을 넣은 패킷으로 Claude가 내리는 판단과 그 복기
- 두 시장 책을 나란히 보는 홈 히어로

## 4. 요구사항 (한국이 다른 점)

### 4-1. 장부·체결 (K4·K5·K6)
- 통화 ₩, 수량은 정수 주, 체결가는 **호가단위**로 반올림한 관측가 × (1 ± 슬리피지 bp). 매수 수수료, 매도 수수료 + 거래세(설정, §7에서 세율 확인).
- 관측치 = **토스 종목 일봉**(그날 밤 수집, 시가·고가·저가·종가·거래량) → `NEXT_CLOSE`(다음 거래일 종가)·`NEXT_OPEN`(다음 거래일 시가). `NEXT_OBSERVATION`은 두지 않는다(장중 관측치 없음).
- 확정 종가 = **금융위 공식 시세**(익일 13시 이후). 토스 봉과 금융위 종가가 다르면 금융위로 보정하고 `reconciled` 기록(둘 다 저장).
- 분할·병합·액면 변경: 3중 조건(가격비·거래량비·순자산 연속성)으로 판정, 못 채우면 그 종목 주문 보류.
- 배당은 1단계 장부에서 반영하지 않는다(미국 책과 같은 조건) — 화면에 적는다.

### 4-2. 규칙 계좌 `kr_rules` (K7·K10)
- **재선정일**(설정: 월 1회 첫 거래일 또는 월 2회 첫·셋째 월요일의 다음 거래일)에만 매수. 그 밖의 날은 매도 신호·스탑·남는 현금의 단기채 ETF 관리.
- 후보 = 수급 유니버스(토스 수급이 있는 종목) 중 **외국인·기관 동시 순매수 연속 거래일 ≥ N**(기본 3)이고 20거래일 누적 순매수가 양수인 종목.
  점수 = 외국인·기관 누적 순매수 금액의 시총 대비 비율 합(동조 가산). 재무 필터: DART 있는 종목은 부채비율 ≤ 상한·ROE > 0, **DART 없는 종목은 '자료 없음'으로 제외**(ETF는 유니버스 밖).
- 상위 `rulesMaxNames`(기본 15) 동일비중 또는 점수 비례(설정), 종목 비중 상한·최소 금액은 설정 공통. 매도 신호: 외국인·기관 동시 순매도 연속 ≥ N 또는 재선정일에 후보 밖.
- 트레일링 스탑·재진입 금지는 미국 책 공통 설정을 쓰되 **키가 다르면 한국 설정 행**(`kr.*`)으로 분리한다 — 규칙 계좌 영향 키 경고 유지.

### 4-3. Claude 계좌 `kr_claude` (K8·K9)
- 패킷 섹션: `0_instructions`(한국 시장 규칙·거래 단위·세금 안내) · `1_basis`(KOSPI·KOSDAQ·원/달러·엔/원·코스피200 야간·KRX 선물 투자주체·국면) · `1b_calendar`(금통위 상수·주요 발표 — 출처 §7) · `3_kr_macro`(한국 금리·BIS 신용갭은 5단계) · `8_prices`(유니버스 가격·수급 요약) · `8b_fundamentals`(DART 재무, 사업보고서 기준일 ≤ 기준일) · `9_portfolio` · `11_notes` · `11b_events`(한국 RSS 사건).
- 프레임(투자 OS): **미국 책과 같은 판을 공유**하고, 시스템 프롬프트 끝에 시장 특수 블록(한국 규칙·단위)을 코드가 붙인다. 한국판 프레임이 따로 필요해지면 그때 결정.
- 결정 시각 기본 **22:00 KST**(토스 일봉·수급 수집 뒤, 서버 창 안). 기준 거래일 = 그날(한국 세션이 끝난 날).
- 스키마는 미국 책과 같은 판(3단계에서 v3로 함께 올림). 검증기 규칙은 설정 공통 + 한국 추가(호가단위·거래세 반영 최소 금액).

### 4-4. 벤치마크 (K2)
- `kr_bench_k200`: KODEX 200(069500) 100%. `kr_bench_mix`: KODEX 200 60% · 단기채 ETF 40%(후보 KODEX 단기채권 153130 — §7에서 가격 출처 확인 뒤 확정).
- 초기화 때 출발일 종가로 사후 체결. 분기 리밸런싱 없음(미국 60/40과 같은 규칙인지 확인해 맞춤).

### 4-5. 데이터·스키마 (K3·K4)
- 수집기: `fsc_prices`에 `open`·`high`·`low` 저장 추가(필드 `mkp`·`hipr`·`lopr`), 새 태스크 `kr_paper_quotes`(토스 종목 일봉, 유니버스 + ETF 2) → 스냅샷 `paper.kr.quotes`, 10년 이력은 금융위 400일 + 토스 봉 200개 상한이라 **출발 시점부터 쌓는다**(이력 부족을 화면에 적음).
- 스키마 V13: `paper_books.market TEXT NOT NULL DEFAULT 'US'`, `currency TEXT NOT NULL DEFAULT 'USD'`, 한국 설정 행, 체결 표에 `fee`·`tax` 열(없으면 추가).
- 데이터셋 이름은 `catalog.py`·`Datasets.java` 양쪽(`DatasetsParityTest`).

### 4-6. 화면
- 모의매매 탭 `/paper/kr/*` — 미국과 같은 패턴. 홈 히어로에 미국·한국 탭. 통화·단위·거래일 달력만 다름.

## 5. 수용 기준
- 네 계좌가 출발일 종가로 초기화되고 벤치마크 두 계좌의 순자산이 ETF 종가 변화와 일치한다(슬리피지·수수료 오차 이내).
- 주문이 다음 거래일 봉으로만 체결되고, 기준 거래일 이하 봉·주문보다 오래된 저장본으로는 체결되지 않는다(테스트).
- 호가단위 반올림·거래세·수수료가 손계산과 같다(테스트, 세율은 설정값).
- 토스 봉과 금융위 종가 불일치가 기록되고 금융위로 보정된다(테스트).
- 재선정일에만 매수 주문이 나오고 후보 산정이 손계산과 같다(테스트). DART 없는 종목은 후보에서 빠지고 사유가 보인다.
- 한국 거래일 달력이 천문연 공휴일·주말·임시휴장(설정)으로 다음 거래일을 맞게 낸다(테스트).
- 미국 책 테스트가 전부 그대로 통과한다(`Market` 추상화 뒤 회귀 0).
- 새 경로 전부 운영자 전용(`AccessPolicyTest`), `make test` 통과, CI 녹색.

## 6. 화면에 반드시 적을 한계
- 장중 관측치 없음(서버 밤 창), 체결은 다음 거래일 봉. 금융위 확정 종가는 하루 늦게 들어와 보정될 수 있음.
- 수급 유니버스 최대 100종목(토스 호출 상한). 가격 이력은 출발 시점부터(장기 통계는 표본 부족).
- 배당 미반영. 세율·수수료는 설정값이며 실제 증권사와 다를 수 있음.
- 규칙 계좌 백테스트는 수급 이력이 쌓인 뒤(2026-10-26 기준 20거래일).

## 7. 선행 확인 — 구현 전에 (단계 0)
1. 금융위 `getStockPriceInfo_V2` 응답에 `mkp`·`hipr`·`lopr`가 실제로 채워지는지, **ETF(069500·153130)가 포함되는지**. 아니면 증권상품시세 API(`getETFPriceInfo`) 또는 토스 봉으로 벤치마크 가격.
2. 토스 종목 일봉 엔드포인트(`/api/v1/stocks/{code}/candles` 또는 Vibe가 쓴 `/api/v1/candles`)가 우리 키로 되는지, 시각·수정주가 여부, 하루 호출 수.
3. 2026년 증권거래세·농특세율(코스피·코스닥)과 호가단위 표. 설정 기본값으로 넣고 출처를 적는다.
4. 한국 RSS 피드(한국은행·금융위·금감원·연합인포맥스 등) 응답과 발행 시각 형식. TradingView 캘린더에 KR 이벤트가 있는지.
5. 임시휴장(수능일 등)과 장 운영 시간 변경을 어디서 받는지. 없으면 설정값.
6. `UsMarketCalendar` 참조 21개 파일의 `Market` 인터페이스 전환 계획(파일별)과 회귀 테스트 목록.
